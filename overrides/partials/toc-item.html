{#- Overrides partials/toc-item.html (mkdocs-material 9.x). Makes the sidebar table of contents collapsible: headings that have sub-headings render as the theme's own md-nav__item--nested toggle nodes (the exact checkbox markup the left sidebar sections use), so every branch starts collapsed and can be expanded/collapsed in place. Leaf headings keep the stock plain-link rendering. Each toggle id is derived from the heading's URL fragment (mkdocs slugs guarantee those are unique within a page), so this file is self-contained and partials/toc.html stays stock. javascripts/toc-collapse.js auto-expands the branch of the heading currently being read. A stray div or label with that class throws and aborts the theme's entire component initialization, which also disables the sidebar height binding and leaves long sidebars unscrollable.
